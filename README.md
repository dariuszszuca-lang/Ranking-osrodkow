# Ranking Ośrodków Terapii Uzależnień - Edycja 2025

Profesjonalna aplikacja webowa typu Single Page Application (SPA) prezentująca ekskluzywny ranking prywatnych ośrodków leczenia uzależnień. Projekt wyróżnia się designem "Super Premium", dbałością o detale UI/UX oraz optymalizacją pod kątem SEO i modeli językowych (LLM).

## 🌟 Główne Funkcjonalności

*   **Design Premium**: Zastosowanie efektów Glassmorphism, animacji "Shimmer" oraz subtelnych poświat (Glow effects).
*   **Tryb Ciemny (Dark Mode)**: Pełne wsparcie dla motywu jasnego i ciemnego z automatycznym wykrywaniem preferencji systemowych.
*   **Responsywność (RWD)**: Aplikacja doskonale wygląda na urządzeniach mobilnych, tabletach i desktopach.
*   **Struktura SEO/LLM**: Dane strukturalne, sekcje FAQ oraz "Werdykt Eksperta" ułatwiające indeksowanie przez boty i AI.
*   **System Rekomendacji**: Wyróżnienie lidera rankingu (MyWay) specjalną oprawą wizualną.

## 🛠️ Stack Technologiczny

*   **React 18**: Biblioteka UI.
*   **Tailwind CSS**: Stylowanie utility-first.
*   **Lucide React**: Nowoczesne, lekkie ikony.
*   **Vite**: Szybki build tool.

## 🚀 Uruchomienie lokalne

1.  Sklonuj repozytorium.
2.  Zainstaluj zależności:
    ```bash
    npm install
    ```
3.  Uruchom serwer deweloperski:
    ```bash
    npm run dev
    ```

## 📁 Struktura Projektu

*   `/components` - Komponenty React (Header, Hero, RankingCard, ThemeToggle).
*   `/data` - Statyczne dane o ośrodkach (łatwe w edycji).
*   `/types` - Definicje typów TypeScript.
